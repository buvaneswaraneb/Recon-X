🚀 Overview

Recon-X is a lightweight yet powerful Linux-based reconnaissance toolkit built for developers, cybersecurity enthusiasts, and ethical hackers.

It integrates system intelligence, network analysis, and OSINT capabilities into a single streamlined CLI tool—making information gathering faster, smarter, and more efficient.

⚙️ Features
🖥️ System Intelligence
CPU usage and performance stats
RAM and memory monitoring
OS details and architecture
🌐 Network Reconnaissance
Local and public IP detection
Hostname and network configuration
Open port scanning
🔎 OSINT Capabilities
Phone number intelligence (carrier, region)
IP intelligence (ISP, approximate location)
📍 Ethical Tracking
Consent-based tracking
Privacy-focused design
🧪 Usage
# System information
python main.py --system

# IP intelligence
python main.py --ip 8.8.8.8

# Phone number OSINT
python main.py --phone +919876543210

# Port scanning
python main.py --scan 127.0.0.1
